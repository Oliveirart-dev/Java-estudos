# Desafio Conta Bancária - Java

Projeto desenvolvido para simular a criação e leitura de dados de uma conta bancária via terminal.

## 🚀 Funcionalidades
- Leitura de nome do cliente, número da conta, agência e saldo via `Scanner`.
- Formatação de saída com dados bancários.

## 🛠️ Tecnologias
- Java 17+
- IntelliJ IDEA
